# 判断の記録 ADR-20 の反証の試み（条 A-2.3 の形）

- 対象: 判断の記録 ADR-20「周の引き金から外す辺の欄を、規範の欄に入らない辺に限り、憲法の前文と schema 節は判断の記録の改訂の欄を通して引き金に数える」（proposed・`design-intent/adr/ADR-20.yaml`）。
- 実施: 2026-09-24。**これは独立の検証役ではない。** 起草役が論点ごとに自分の案を崩しにかかった記録である。起草役と同じ文脈なので、見落としの向きが揃っている恐れがある。独立の検証役（別の文脈・読み取りだけ）は席が別に立てる（§5 に検証役へ渡す問いを置いた）。
- 本判断は憲法の条文を改訂しないので、判断の記録の欄の決まりは反証の記録を必須にしていない。発効した判断の記録 ADR-18 の決定の範囲を改め、その字を書き換えるので、ADR-18・ADR-19 の先例に倣って前置した。
- 数えの script: `~/.local/share/folio2/handoff-2026-09-24/adr20-scripts/`（`trigger_probe.sh` = 写しに変更を当てて印を導出し直し、引き金の要約値と床の終了コードを見る／`intervals.py` = 周 2〜31 の base の間の 29 区間で、引き金の一覧の写しと辺の欄と前文と schema 節の動きを数える）。どちらも再実行できる。
- 実測の土台: 枝 `docs/adr20`（一括 17 の枝 `0e7901c` の上）で `cargo build --all-targets` した `target/debug/folio`。周の区間は各周の依頼文の「main <7 桁>」（30 周目は枝 `b0be15b`）。

## 1. 改訂が主張する利益と、失うもの

- 主張する利益: 判断の記録 ADR-18 の決定 (1) と (2)（と語彙・索引の欄の決まりの注）が同じ差分に逆の答えを出す食い違いが消え、次の周の整合が同じ所で 止める を出さなくなる。前文と憲法の schema 節の変更が周を起こすかが、字の上で定まる。引き金の漏れの撤退条件が 1 つの数えにまとまる。
- 主張しない利益: 周の数の増減。過去 29 区間では、どの案でも回す周の数は変わらない（§2）。
- 失うもの（と疑われるもの）: 発効した判断の記録の決定の字を書き換える先例ができること。前文と schema 節の扱いが型付きの定数でなく床との結び付きに依ること。

## 2. 数え直し

### 2.1 どの変更が引き金を動かすか（trigger_probe.sh・実物の道具で測った）

| 写しに当てた変更 | 引き金の要約値 | 床（folio check） |
|---|---|---|
| 変更なし（基準） | 基準の値 | 0 |
| 前文の本文の 1 字 | **動かない** | 1（条 N-4: 現行の写しが凍結 anchor と違う） |
| 前文の平易文の 1 字 | **動かない** | 1（同） |
| 憲法の schema 節の値 1 つ | **動かない** | 1（同） |
| 憲法の schema 節の行の注釈（YAML の注釈）の 1 字 | 動かない | 0（注釈は値でなく、凍結の写しにも入らない） |
| 受入基準 AC18 の確かめる要件に id を足す | **動く** | 0 |
| 要件 FR20 の確かめ方の中の受入基準に id を足す | **動く** | 0 |
| 規則の表の行 D-12 の条を替える | **動く** | 1（条の関係の欄と食い違う・本題の外） |
| 規則の表の行 D-12 の参照の欄に id を足す | 動かない | 0 |
| 判断の記録 ADR-18 の根拠に id を足す | 動かない | 0 |
| 要件 FR20 の根拠に id を足す | 動かない | 0 |
| 発効した判断の記録 ADR-17 の改訂の欄に 1 件を足す | **動く** | 1（改訂の記録が差分と消し込めない・本題の外） |

- 30 周目の所見 F-1 の主張（3 つの辺の欄は引き金を動かす・ほかの辺は動かさない）は実物で再現した。
- 所見 F-4 の主張（前文と schema 節だけの変更は、引き金の一覧の上では引き金にならない）も再現した。ただし同じ変更は床が落とす。
- 索引の辺の欄（実装の `EDGE_FIELDS`）と引き金の一覧（`ceiling.rs` の定数）の重なりは、確かめる要件・確かめ方の中の受入基準・規則の表の行の条の 3 つだけ。要件書の目的と範囲の節（丸ごと引き金に入る）の中に辺の欄は無い（写しを歩いて確かめた）。判断の記録の改訂の欄（amends）は索引の辺の型に在るが、辺の欄の一覧には入らず本文の側に残る（graph.yaml の注）ので、食い違いの外である。

| 項目 | 値 |

| 引き金の一覧の写しが動いた区間 | 23 |
| 3 つの辺の欄が動いた区間 | 11 |

## 3. 反証の試みと応答

### ① 食い違いは本当に在るか・決定 (2) を狭めれば解けるか — 支持

- 反証の試み: 決定 (2) の「辺を足すだけの変更」は、節点の要約値（索引）の話で、引き金の話ではないと読めば、食い違いは無い。
- 応答: 退ける。30 周目の反証も同じ読みを退けた。ADR-18 の決定 (2) は「引き金の外の変更では周を回さない」の段の文で、語彙の「周の引き金」も索引の注も「周の引き金にならない」と引き金について言う。食い違いは字の上に在る。
- 反証の試み 2: 狭めた後も、ほかの所で同じ型の食い違いが残るのではないか。
- 応答: 引き金の一覧と辺の欄の重なりを全数で当てた（§2.1）。重なりは 3 つだけで、狭めた字はその 3 つを名指す。残る辺の欄（関係・参照・根拠・目的・規則・判断の記録・帰結）はどれも引き金の一覧に無い。判断の記録の改訂の欄と図の欄は索引の辺の型に在るが辺の欄ではない（本文の側）ので、決定 (2) の断りの対象ではない。
- 残る危うさ: 判断の記録 ADR-13 の決定 (8) の本文「辺を足すだけの変更は引き金に数えない」は書き換えない（ADR-18 が既に狭めた決定で、今の引き金の定義は ADR-18 が持つ）。次の周の整合が ADR-13 の本文を拾う恐れがある。ADR-13 の注で断り（決定 (5) ④）、拾われたら撤退条件 (3) で数える。

### ② 精度を落とさないか — 支持

- 反証の試み: 3 つの辺の欄を引き金に数えると、確かめる要件を 1 つ足すだけの小さな直しにも周が要り、実時間が増える。
- 応答: 過去 29 区間では 3 つの辺の欄だけが動いた区間は 0 で、増える周は 0 だった。今後そういう直しが続けば撤退条件 (2) が数え、2 周で案 b を持ち主に問う。逆向き（3 つを外す案 b）は、完成の物差しの結び付き（どの受入基準がどの要件を確かめるか）と規則の縛る先（行の条）の変更を読まずに通すので、精度が落ちる。場所が 3 つの欄に置かれた所見は 31 周で 1 件（直す）しかなく、止める は 0 件なので、案 b の精度の損も過去には現れていない。どちらも過去の数では差が出ず、精度を先にする目的関数（ADR-13 決定 (0)）で案 a を採る。

### ③ 前文と schema 節を判断の記録の改訂の欄で数える形は漏れないか — 条件付き支持（撤退条件 (1) を置いた）

- 反証の試み 1: 型付きの一覧に無い欄を「規範の欄」と呼ぶのは、一覧の正本を実装の型付きの定数に置く ADR-18 決定 (1) と、条 P-5.1・P-5.6 に反する。天井の正本の生成区間の写しを読む審査役は、前文が一覧に無いのを見て、決定 (1) ① と食い違うと拾う。
- 応答: 一部受け入れた。決定 (2) の字で「前文と schema 節は一覧の型付きの定数に入れず、② の改訂の欄で数える」と明記し、天井の正本の引き金の注（生成区間）にも同じ断りを入れる便を決定 (5) ⑤ に置いた。数え方そのもの（どの欄の変化で要約値が動くか）は型付きの定数だけが決める状態は変わらない（前文を数えるのは ② の改訂の欄の定数で、それは一覧に在る）。散文にしか無い規則を足していない（条 N-2）。便の着地までは、生成区間の注に断りが無いので、拾われる恐れが残る。
- 反証の試み 2: 結び付きは床が合格する本流の上でだけ成り立つ。床が「まだ分からない」の写し（版管理が無い・浅い写し）や、床を撃たずに取り込んだ変更では、前文だけが変わって引き金が動かないことが起きる。自動の仕掛けを保証として設計しない（条 P-15.1）に反する。
- 応答: 受け入れた。これは本判断の中で最も弱い所である。本流の取り込みは席の床 4 本と取り込みの審査が守っていて、仕掛けが保証しているわけではない。だから撤退条件 (1) を、周の結果を待たない決定的な数え（印の base と門を撃つ本流の組で、前文か schema 節が違うのに引き金が同じ）にし、1 件で定数に足す形（案 d）へ移す。期間も切らずに数え続ける。起草の時点の実測では過去 2 区間のうち 2 で結び付きが成り立っていた。
- 反証の試み 3: 前文と schema 節は、平易文や根拠の行まで丸ごと改訂の範囲に入る。ADR-18 の考え方（平易文や注は引き金の外）と合わない。
- 応答: 受け入れて字に書いた（決定 (2) の「平易文や注の字を含めて丸ごと改訂の範囲に在るので…引き金の側に入る」）。前文の平易文の直しでも判断の記録の発効が要る（条 A-2・床が落とす）ので、周を起こさない道がそもそも無い。案 d でも同じく引き金に入る。ADR-18 の「平易文は引き金の外」は、改訂の範囲の外の平易文についての定めと読む。
- 反証の試み 4: 案 d（定数に足す）なら、床に依らず直接数えられ、型付きの一覧と字が 1 対 1 になる。精度を先にするなら案 d ではないか。
- 応答: 案 d で拾える変更は、床が合格する本流の上では案 a と同じ（過去 2 区間のうち 2）。違いは「床を経ない変更」だけで、それは撤退条件 (1) が 1 件で拾って案 d へ移す。案 d は今すぐ実装の便と印の付け直しを要する。持ち主が案 d を選ぶのも筋は通るので、承認要求の代替案に並べた。**起草役はここを五分に近いと見ている。** 席の指示（実装の式を変えない）に沿って案 a を推奨にした。

### ④ 発効した決定の字を書き換えてよいか — 条件付き支持（先例と違うことを明記した）

- 反証の試み: 今までの判断の記録は、発効した決定の本文を 1 字も変えず、注で断るか、改訂する側の改訂の欄だけで範囲を変えてきた（ADR-13 の注 (e)・ADR-3 の注「発効済みの判断の記録なので案の字は変えない」）。一括 17 の問 8 も「発効した ADR-18 の決定の字は書き換えない（判断の記録の欄の決まりは、発効した判断の決定の範囲を別の判断の改訂の欄で変える形だけを持つ）」と持ち主へ説明した。書き換えは、持ち主が見た前提と違う。
- 応答: 受け入れて、承認要求の 🔴 の中で先例と違うことを明記し、書き換えない形を代替として並べた（docs/design/adr-20.md §2）。書き換える理由は、両立しない 2 文が決定の本文に残る限り次の周の整合が同じ所を拾うことで、これは一括 17 の問 8 自身が「注で (1) が (2) に優先すると断る向き」を退けた理由と同じである。改訂の欄だけで範囲を変えても、ADR-18 の本文の 2 文は残る。改める前の字は本判断の決定 (1) (2) に逐語で残し、版管理の履歴にも残る。判断の記録の欄の決まりは決定の本文の書き換えを禁じていない（床も見ない）が、欄の決まりの改訂の欄の注は「改訂される側に来歴の欄は置かない」とするので、ADR-18 の側には来歴の欄を置かず、注の 1 段で断る。
- 残る危うさ: 書き換えた後の ADR-18 の決定の字は、持ち主が 2026-09-24 11:51 JST に承認した字ではない。承認欄の逐語と決定の字の対応が崩れる。ADR-18 の注と本判断の承認で結ぶ。

### ⑤ 他の判断の記録の撤退条件の数え方を本判断が決めてよいか（決定 (4)）— 条件付き支持

- 反証の試み: ADR-13 の撤退条件 (6) の効力を ADR-20 の決定で変えるのは、判断の記録の欄の決まりに無い形である（改訂の欄は決定の番号しか指せない）。
- 応答: 本判断は (6) の効力を変えていない。(6) と ADR-18 の (1) は同じ出来事を同じ閾値（2 件）で数え、戻し先も同じ形である（文脈 (1)・決定 (4)）ので、数える主体を 1 つにしても効き目は変わらない。本判断が決めるのは「同じ数を二重に数えない」ことだけで、ADR-13 の撤退条件の字は変えず注で断る。一括 17 の問 8 のコストの欄と承認の後の欄の 18 が、この数え方を本判断で決めると持ち主へ示していた。
- 反証の試み 2: ADR-13 の決定 (8) を改訂の欄に挙げる（widen）のは要るか。ADR-18 が既に (8) を狭めている。
- 応答: (8) の本文に「辺を足すだけの変更は引き金に数えない」が在り、索引の注も「ADR-13 決定 (8)」を出所に挙げる。本判断はその断りの範囲を狭めるので、改訂の欄に挙げて片側の記録を残した（欄の決まりのとおり ADR-13 の側には来歴の欄を置かない）。

### ⑥ 憲法と先の判断に反しないか — 支持

- 条 P-5.1・P-5.6: 引き金の一覧の正本は実装の型付きの定数のまま、写しは生成区間のまま。字の揃えの便は生成区間の字の正本（実装の文字列）を直す。
- 条 P-6.3・P-6.4: 生成区間を手で直さない。索引と天井の正本の注は便で直す。
- 条 P-7: 番号を再利用しない。要件書は版を上げ、規範文と番号は変えない。
- 条 P-8.1: 撤退条件は 4 つ、種類は measure。
- 条 A-2・N-4: 憲法の条文・前文・schema 節は 1 字も変えない。前文と schema 節の改訂の手続きも変えない。
- 条 N-2: 散文にしか無い規則を足さない（③ の応答 1）。
- 条 N-3.1: 例外の口を足さない。辺の断りを狭めるのは例外を減らす向き。
- ADR-18 決定 (0)（精度を先に）: 規範の結び付きを読む側に倒した。
- ADR-19 と規則の表の開発規律行 D-14: 字の揃えの便（生成区間）は、枝に書けない所見の運び方と同じく、次の周の前に運ぶ。

### ⑦ 別の周が同じ型の穴を拾わないか — 残る（本判断の外）

- 憲法の最上位の節のうち、改訂の範囲（schema・前文・条）の外の節（目的の北極星〔north_star〕・改訂の手続きの章・規則と用語集の指し先・出所）は、決定 (1) の一覧にも決定 (2) の引き金の外の列にも名指されていない。北極星は 2026-09-12 の初版から 1 度も変わっていない。30 周目の F-4 と同じ型の所見（一覧が閉じていない）がここに立つ恐れがある。本判断に混ぜず、承認要求の「まだ分からないこと」に置いた。

## 4. 起草役の総合

- 骨（決定 (2) の断りを 3 つの辺の欄だけ狭める・実装の式を変えない）は、実物で再現した食い違いの範囲と、過去の区間の数で崩れなかった。
- 前文と schema 節の扱いは、床との結び付きに依る点が弱い。撤退条件 (1) を決定的な数えにし、戻し先を案 d に置いたが、案 d を最初から採る判断も同じくらい筋が通る。
- 決定の字の書き換えは先例と違う。承認要求で問う。

## 5. 独立の検証役へ渡す問い（席が立てる）

1. `intervals.py` と別の道（例えば実物の道具で区間ごとに写しを組み、印を導出し直す）で、29 区間の「3 つの辺の欄だけが動いた区間 = 0」「前文か schema 節が動いた区間 = 2・うち判断の記録の欄も動いた = 2」を数え直す。
2. 引き金の一覧と辺の欄の重なりが 3 つだけか（`ceiling.rs` の定数と `graph.rs` の `EDGE_FIELDS` を読み、要件書の丸ごとの節の中を含めて）。
3. 床が合格する 2 つの状態の間で、前文か schema 節が変わり、発効した判断の記録の欄（ADR-18 決定 (1) ②）が変わらない道があるか（凍結 anchor の列・執筆中の版・退役した判断の記録・改訂の欄を先に書いた提案中の判断の記録を含めて）。
4. ADR-18 の決定の字を書き換える形と、書き換えずに改訂の欄と注だけで範囲を変える形のどちらが、次の周の整合の 止める を減らすか。
5. 決定 (5) の字の揃えの文案（承認要求 §4）が、それぞれの置き場の床（語彙の英字語・散文の言及の規則 R-17・生成区間の凍結の写し）を通るか。
