## 1. 要旨（平易に）

- 次の段（M3）は「folio2 以外の場所で、folio2 の道具の検査に合格できるか」を確かめる段で、その相手を scribe2 にしていた（判断の記録 ADR-16）。

- **やりたいこと**: 判断の記録 ADR-21 を発効する（案 a）。発効の後に、席が §3 の欄を書く。便は起こさない。

## 6. まだ分からないこと

- **「1 つの repo」がどの repo か。** 新しい repo か、scribe2 か folio2 の repo を育てるのかは連絡に無い。folio2 の repo を育てる形なら、v3 の置き場は最初から folio の実装と同じ repo に在り、撤退条件 (1) が発効の直後に当たる。
- **合流の時機。** folio の実装が v3 の repo へ入るのが、判定点 ①〜③ の記帳の前か後か。
- **v3 の境界の形。** v3 の器が導出物の file を読むか、同じ組み立ての束の中で型を直に受けるか。型なら判定点 ②③ を問い直す（撤退条件 (2)）。
- **v3 の最初の便を運ぶ器。** 今の器（scribe2 の組み立て）の見込みが高いが、決まっていない。器の受け口 s2-07l.473 は再開済み・未着地。
- **v3 の台帳の接頭辞。** 承認欄の裁定 id の形（英字 1 字と数字 1 字の接頭辞）に合わなければ、床が承認欄を落とす（ADR-16 の (ア)〜(キ) に無い種類）。「1 つの台帳」が folio2 の台帳を育てたものなら、判定点の記帳の置き場（利用者の台帳）と f2-648 が同じ帳簿になる。
- **撤退条件 (3) の 30 日。** 根拠は M3 の口が使われないまま置かれる期間を区切ることだけで、v3 の着手の予定は連絡に無い。
- **独立の検証。** 自己反証だけで、別の文脈の検証役の反証はまだ無い。渡す問いは grill の §5。
