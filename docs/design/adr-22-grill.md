# 判断の記録 ADR-22 の反証の試み（条 A-2.3 の形）

- 対象: 判断の記録 ADR-22「契約表を『folio2 の M1 で設計ノートの YAML 正本と導出物へ移す』とした順序を閉じる — ADR-3 の決定 (8) の範囲を狭め、ADR-16 の決定 (1) の『M3 の後に改めて問う』の句を閉じる」（proposed・`design-intent/adr/ADR-22.yaml`）。
- 実施: 2026-09-24。**独立の検証役ではない。** 起草役（orchestrator 席の起草役・fable 5.1）が論点ごとに自分の案を崩しにかかった記録である。起草役と同じ文脈なので、見落としの向きが揃っている恐れがある。席が独立の検証役を立てるなら、§5 の問いを渡す。
- 本判断は憲法の条文を改訂しないので、判断の記録の欄の決まりは反証の記録を必須にしていない。発効した判断の記録 ADR-3 と ADR-16 の決定の範囲を狭めるので、ADR-18〜ADR-21 の先例に倣って前置した。
- 材料: 天井の 32 周目の束（`~/.local/share/folio2/ceiling/2026-09-24-round32/2026-09-24-round32/coherence/` の `findings.yaml` の F-1〜F-3 と `refute/F-1/result.yaml`）と反証の記録 `refute-notes/coherence-F-1.md`。判断の記録 ADR-3・ADR-16・ADR-20・ADR-21 と `adr/schema.yaml` の改訂の欄の注。要件書の制約 CON8・M1 と M3 の範囲の節・要件 FR11。
- 実測の土台: 本流 `68196cf` の上の枝 `docs/adr22`。床は本流の `target/debug/folio`。

## 1. 改訂が主張する利益と、失うもの

- **主張する利益**: 発効した判断の記録どうしの食い違いが消える。今は ADR-3 決定 (8) が「M1 で scribe2 の契約表を YAML 正本と導出物へ移す」と言い、ADR-16 が「導出物は M3」、ADR-21 が「scribe2 の設計文書は移らない」と言う。32 周目の整合の 止める（反証 支持）が解け、同じ根の 直す 2 件（CON8 の頭の文・M3 の範囲の節の問う句）も、指す先の判断の記録が閉じた字を持つので直せる。
- **主張しない利益**: 新しい向き。段を M3 に置いたのは ADR-16、scribe2 を外し v3 に当てたのは ADR-21 で、本判断はその帰結を ADR-3 決定 (8) の側に記帳するだけである。
- **失うもの（と疑われるもの）**: 「scribe2 の設計文書のどこまでを移すか」の論点の置き場が消える。scribe2 が移行を再開したとき、戻す判断の記録が 1 本増える（撤退条件 (1)）。

## 3. 反証の試みと応答

### ① 食い違いは本当に在るか（M1 を過ぎた決定は自然に失効していないか）— 支持

- 崩しの試み: (8) は「M1 で」と時期を書いた決定で、M1 が過ぎたら役目を終えた、と読めないか。
- 応答: 判断の記録の失効の口は状態（status）と置き換えの欄と改訂の欄だけで、時期が過ぎた決定を自動で閉じる口は無い（欄の決まり）。M1 のあいだに (8) は果たされず（scribe2 の契約表は 1 本も移っていない・要件 FR11 は保留から M3 へ）、ADR-16 案 d の理由は (8) を今も生きた向きとして引いている。32 周目の反証も同じ読みを退けた。

### ② 改訂の欄の向きは narrow でよいか — 条件付き支持（注に向きの読みを書いた）

- 崩しの試み: M1 から M3 へ段を動かすのは「狭める」でも「広げる」でもない。M3 に義務を足すなら広げる向きではないか。
- 応答: 段を M3 に置いたのは ADR-16 決定 (5)(7) と要件 FR11 の段の欄で、本判断は M3 に義務を足さない。本判断が (8) にすることは、M1 の段の義務を外すこと・移す相手から scribe2 の契約表を外すこと・範囲の論点を閉じることの 3 つで、どれも範囲を減らす。YAML 正本の節から導出物を作る向きを v3 の置き場の契約表に当てるのも、ADR-21 決定 (1) の判定点 ②③ が既に持つ。
- 条件: この読みを判断の記録の注の【改訂の欄の向き】に書いた。向きが本当かは人が読む（欄の決まり）。

### ③ ADR-16 決定 (1) の末尾の句まで閉じてよいか（本判断の範囲を広げすぎていないか）— 条件付き支持（改訂の欄の 2 行目に分けた）

- 崩しの試み: 所見 F-1 は ADR-3 決定 (8) だけを名指した。ADR-16 決定 (1) の句は ADR-21 が「M3 に入れないものの列は変えない」とした列の一部で、触ると ADR-21 の承認の範囲に踏み込まないか。
- 応答: 句は列の外の問う句で、(8) の (イ)（範囲の論点）の時機を定め直した字である（ADR-16 注 (e)）。(8) の (イ) を閉じて句を残すと、要件書の M3 の範囲の節が「閉じた」と書き、ADR-16 決定 (1) が「改めて問う」と言う形が残り、F-1 と同じ形の所見を次の周が拾う（F-3 は既にこの句を名指している）。ADR-21 は列の中の「利用者の憲法・判断の記録・調べものの文書の移行」を当たる物が無いと読んだだけで、問う句には触れていない。本判断は同じ読みを問う句に当て、列は変えない。
- 条件: 2 行目の要約に「M3 に入れないものの列と判定点 ①〜③ は変えない」を書いた。承認要求の 🔴 に 2 行とも載せる。

### ④ 閉じた範囲の論点は本当に相手が無いか — 条件付き支持（撤退条件 (1)(2) を置いた）

- 崩しの試み: scribe2 は前の版の道具のまま畳むが、畳んだ後に scribe2 の設計文書を v3 へ持ち込むことはないか。v3 以外の外部の利用者が散文の設計文書を持って来ることはないか。
- 応答: v3 は scribe2 の中心の部分を合流させる世代だが、設計文書は folio init の骨格から新しく書く（ADR-21 文脈 (1) の (ウ)）。持ち込むときは、それは「移す」で、ADR-21 の撤退条件 (4)（scribe2 の移行の再開）か本判断の撤退条件 (2)（移す相手の出現）に当たる。
- 条件: 撤退条件 (1)(2) で、論点をその利用者について開き直す口を置いた。

### ⑤ folio2 自身の設計ノートの移行と混ざらないか — 条件付き支持（決定 (2) の末尾と帰結に書いた）

- 崩しの試み: docs/design の便の設計ノート 43 本は「M1 で YAML 正本へ移す」と書き、`delivery-23.md` は要件書 CON8 の順序を引いて自分の便の割りを決めた。(8) を閉じると folio2 自身の移行の根拠も消えないか。
- 応答: (8) の (ア) は「scribe2 の設計文書の中の機械が読む区間」を相手に名指しており、folio2 自身の設計ノートは相手ではない。folio2 自身の設計ノートの移行中の扱いは語彙の「設計文書」の項の注が持つ（「YAML の設計ノート（design-note/）へ移すまでは天井の読む文書の外」）。本判断はそれを変えない。
- 条件: 決定 (2) の末尾と帰結にこの境界を書いた。folio2 自身の設計ノートを YAML へ移す時機と範囲を決めた判断の記録は、起草の読みでは見つからない（§6）。

### ⑥ 注だけで足りないか（判断の記録 1 本は重すぎないか）— 支持（案 c を退けた）

- 崩しの試み: 中身は ADR-16 と ADR-21 の帰結だけなので、ADR-3 の注に 1 段足せば済むのではないか。
- 応答: 欄の決まりは範囲を変える口を改訂の欄に限り、ADR-21 決定 (6) も同じ。32 周目の反証は注 (e) を (8) を狭めた記録と読む道を退けた。29〜31 周目の ADR-13 決定 (8) の件も注では解けず、ADR-20 の改訂の欄で解いた。注で断ると同じ所見が次の周で 止める に戻る見込みが高い。
- 発効した ADR-21 の改訂の欄に行を足す案（案 e）も、承認された 5 行の外の行を承認なしに足すことになるので退けた。

## 4. 起草役の総合

- 中心（ADR-3 決定 (8) を改訂の欄で狭め、決定の本文は書き換えない）は支持。
- 条件付きで直した所は 2 つ。向きを narrow と読む理由を注に書いた（②）。ADR-16 決定 (1) の末尾の句を 2 行目として閉じた（③）。
- 残る危うさ: 閉じた範囲の論点が別の利用者で開き直る場合（撤退条件 (2)）と、folio2 自身の設計ノートの移行が (8) の読みと混ざる場合（決定 (2) の末尾）。

## 5. 独立の検証役へ渡す問い（席が立てるなら）

1. 改訂の欄の 2 行目（ADR-16 決定 (1) の末尾の句）は、ADR-21 の改訂の欄の 1 行目（同じ決定 (1) を狭める）と重ならないか。読み手が ADR-16 → ADR-21 → ADR-22 をたどって今の読みに届くか。
2. §2.2 の全数の調べ方で漏れる言い回し（例: 「契約表の移行」「YAML へ移す」の別の字）は無いか。
3. 撤退条件 (3) の「導出物を作れなかった回」は、ADR-21 の撤退条件 (2) と二重に数えないか。数える口は決定的か。
4. 要件書 CON8 の頭の文を過去の字にする直しは、制約の本文の意味を変えるので、要件書の版上げ（番号は不変）で運んでよいか。

## 6. まだ分からないこと

- folio2 自身の設計ノート（docs/design の便の契約表と裁定の記録）を YAML 正本へ移す時機と範囲を決めた判断の記録は、起草の読みでは見つからなかった。語彙の「設計文書」の項の注が「移行中」と書くだけである。本判断の外の論点として、席が台帳に控えを起こすかを決める。
