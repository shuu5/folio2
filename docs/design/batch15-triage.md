### 🔴 問 5. 憲法の条 A-1 の平易文と、条 P-13 の機構の注

**やりたいこと。** 2 か所を直す。**条文（id・見出し・規範文・段・縛る相手）と schema 節・前文は 1 字も触らない＝条 A-2.2 の改訂に当たらず、憲法の版は上がらない。**

1. 条 A-1 の平易文 — 前「…の 3 つは、道具が勝手にやらず、決まった対話の場所であなたに確認してからにします。」→ 後「…の 3 つは、道具も、道具を作る側（AI の席や人）も勝手にやらず、決まった対話の場所であなたに確認してからにします。」（忠実さ F-5）
2. 条 P-13 の機構の注 — 前「書き込み先は呼び手が渡す出力先の指定だけだが、そのことを歯で固定してはいない（2026-09-20 時点）」→ 後「書き込み先は、呼び手が渡す指定（出力先・置き場・印の置き場・CLAUDE.md の path）と、そこから決まる固定の path（例 = 置き場の下の天井の印・凍結 anchor の置き場）と、指定が無いときの既定（folio hello の 1 回きりの印は利用者ごとの状態の置き場・folio inject は呼んだ場所の CLAUDE.md・図の道具の作業は一時の置き場）で決まり、v1 の path を既定に持つ口は無い（2026-09-24 に確かめた）。ただしそのことを歯で固定してはいない」（実態 F-5）

**代替案。**

**コスト。** 承認 1 回。平易文の 1 句・機構の注の 1 文。`folio inject --check` の生成区間（前文と規範文）は動かない（枝の HEAD で 68 行 / 7,912 byte 一致）。
